## 🚀 Featured Projects

### 🌾 [AgriSens — AI Crop Yield Prediction](https://github.com/sujaymalipatil/AgriSens)
`Python` · `TensorFlow` · `Keras` · `Streamlit` · `NumPy` · `Pandas`

Hybrid deep learning model combining **CNN + Random Forest** for agricultural crop yield prediction.
- Achieved **94.6% accuracy**, RMSE of 0.069, R² score of 0.94 — outperforming LSTM, Decision Tree & Linear Regression baselines
- Integrated multi-source datasets: weather patterns, soil composition, and geographic data
- Built a **Streamlit web interface** for real-time crop recommendations based on soil pH, nitrogen content, rainfall & temperature
- 📄 Published in **IRJAEH Vol. 04, Issue 01 (Jan 2026)** · [DOI: 10.47392/IRJAEH.2026.0038](https://doi.org/10.47392/IRJAEH.2026.0038)
